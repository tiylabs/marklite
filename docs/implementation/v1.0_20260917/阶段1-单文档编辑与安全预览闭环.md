# 阶段 1：单文档编辑与安全预览闭环

## 1. 项目背景

Marklite 是原生 macOS 本地 Markdown 工具，核心价值是打开即编辑、即时预览与文件安全。本阶段把阶段 0 验证过的接口和技术路线落实为可运行的单文档纵向闭环，而非先搭静态界面再补保存与安全。

依据：[PRD](<../../PRD-1.0(MVP)_20260916.md>) F-01～F-07、E-01～E-04、R-01～R-03、V-01～V-02；[TAD](../../TAD-001-技术架构设计方案_20260916.md) §2～§9、§11、§16～§19；[ADR](../../ADR-001-技术选型与架构决策_20260916.md) D09～D12；[界面 Prompt](../../Prompt-Layout_20260916.md) 的 single-file 场景。Prompt 固定浅色仅用于参考图，实际应用必须支持系统深浅色。

## 3. 目标与边界

### 3.1 目标

- 新建/打开 → 输入与撤销 → 安全实时预览 → 保存/另存为 → 关闭确认全链路可用。
- 从首个窗口接入 en/zh-Hans、主题和基础 AX，从首次渲染落实内容清洗和默认断网。
- 建立可扩展到多文档的会话/窗口分离，禁止采用后续必须推翻的一窗一文本全局单例。
- 用保存快照、文件身份、双基线和明确提交回执保证原文件安全。

### 3.2 本阶段不交付

完整多文档侧栏与目录树、后台草稿调度及启动恢复、系统性外部监控、树内创建/废纸篓、完整查找替换、图片加载、HTML/PDF 导出。相关命令未实现时不得展示可点击的假成功入口；最终菜单必须在阶段 3 补齐。基础安全层应识别资源引用，但未交付资源加载前只显示安全占位，不绕过权限。

阶段 1 的保存前磁盘版本复核与冲突阻断不能延后到阶段 2；正常关闭必须保护未保存修改。所有新开命令也不得静默替换已有有内容的会话。

## 4. 阶段详细设计

### 4.1 S1-01：正式工程与领域契约

按 TAD §2.2 建立：

| 拟交付路径 | 内容 |
|---|---|
| `Marklite/App/` | AppCoordinator、依赖装配、CommandRouter、系统事件入口 |
| `Marklite/Application/` | DocumentSession、WindowSession、最小注册表、Open/Save/Close 协调器 |
| `Marklite/Editor/` | 已验证的 EditorBackend、文本事件、高亮与位置索引 |
| `Marklite/Preview/` | PreviewController、桥接、滚动同步 |
| `Marklite/Infrastructure/Files/` | 授权、身份、读取、安全写入与错误映射 |
| `Marklite/Infrastructure/Rendering/` | 第三方解析适配，不向 UI 暴露 AST |
| `Packages/MarkliteCore/` | 值模型、策略、纯状态归约、SafeDocument 与安全清洗 |
| `WebAssets/`、`Marklite/Resources/` | 本地预览壳/样式/脚本、String Catalog |
| `Tests/`、`Scripts/` | 单元、确定性并发、文件/WebKit 集成与构建入口 |

DocumentSession 在 MainActor 拥有唯一 NSTextStorage/编辑后端及 UndoManager。WindowSession 仅引用 DocumentID，不持文本副本。领域状态包含 revision、LocationEpoch、savedBaseline、diskBaseline、dirty、externalState、activity、viewState；后续 RecoveryEpoch 等契约预留但不伪造持久化能力。

文件写入和解析离开主 actor，跨线程只传不可变快照及 Sendable 值。Core 不依赖 AppKit、WebKit 或第三方 AST；不以 unchecked Sendable 掩盖所有权错误。

### 4.2 S1-02：原生窗口、命令及双语

- NSWindowController + 原生 split 容器，默认 1280×820 pt、最小 800×560 pt，双栏 48/52，各至少 320 pt。
- 标题栏约 48～52 pt，左侧系统按钮与侧栏入口，中间活动文件名/脏点，右侧仅布局与更多图标。图标视觉 16～18 pt、点击区至少 28×28 pt。
- 无独立工具栏行、顶部标签、面板标题、底部状态栏、常驻打开/保存/格式按钮。禁用系统自动窗口标签合并。
- 单文件默认侧栏隐藏，隐藏后正文占满可用宽度；侧栏按钮不得消失。阶段 1 提供最小已打开文档导航投影，完整多会话导航规则由阶段 2 扩展。
- 菜单与标题栏共用 CommandRouter：目标在触发时绑定 DocumentID；执行前复核能力，不随异步焦点变化改目标。
- ⌘N/O/S、⇧⌘S、⌘W、⇧⌘W、⌘1/2/3、⌃⌘S、⌃⌘F 接入系统语义。编辑命令优先 first responder，不把对话框输入框的撤销路由到正文。
- String Catalog 使用稳定键/参数化错误，不拼接句子；英文、简体中文同时维护，遵循系统应用语言，英文回退，无应用内语言切换器。
- ThemeSnapshot 统一编辑/预览外观；切主题不递增 revision、不改脏状态、不跳阅读位置。未保存点和图标均提供双语 AX 名称/状态。

更多菜单最终固定为 Open、Open/Change Folder、Save、Save As、Export、Reveal in Finder；本阶段未交付项按能力禁用，不新增替代工具栏。

### 4.3 S1-03：打开、编码与保存基线

1. 文件面板、Finder、拖放、Recent 接入同一 OpenCoordinator；持有适当授权后解析实际身份与规范化位置。
2. 最小注册表即处理重复打开，不创建同一文件的独立可写副本；完整并发批量路由在阶段 2 完成。
3. 支持 `.md`、`.markdown`、`.mdown`；显式“所有文件”允许可严格解码纯文本，不接收二进制伪装和非法 UTF-8。
4. 记录 UTF-8 BOM、主要 LF/CRLF、混合换行、末尾换行；编辑模型统一 LF。savedBaseline 比规范文本，diskBaseline 比原始字节，刚打开不误判脏。
5. 新建为空白双栏、焦点在编辑器、预览空白，无欢迎卡。新建默认 UTF-8 无 BOM、LF。
6. 首存默认名按语言 Untitled.md/未命名.md，目录为最近保存目录或系统文档目录。仅从未编辑的初始空会话可复用；已有内容绝不因打开被替换。
7. 最近打开使用系统服务并支持 Clear Menu；记录不构成授权。文件关联从工程配置建立，发布包完整验证在阶段 4。

规模策略从打开入口生效：≤1 MB 完整体验；>1～5 MB 可降频；>5～20 MB 提示后默认 Editor；>20 MB 拒绝打开。精确边界按字节测试。编辑中粘贴超限只降级预览，不丢内容、不禁用保存。

### 4.4 S1-04：编辑、判脏与高亮

- 系统等宽字体约 15～16 pt，行高约 1.6，软换行；不显示行号、缩略图、折叠、缩进线、整行高亮。
- 纯文本粘贴；关闭智能引号/破折号/自动改写。Return 继承缩进不续列表；Tab 4 空格，多行统一缩进；Shift-Tab 取消一级，同时遵循全键盘导航优先级。
- IME marked range 不受高亮干扰，不重建编辑器或强移光标。所有程序字符修改经同一入口，正确分组撤销。
- 按TAD §3.4用UTF-16长度快路径＋规范文本字面精确比较判脏；最坏O(n)，不建Merkle树，不把Swift String规范等价当字面相等。Undo回基线同步clean；仅>5 MB经G0批准的超预算场景可用后台比较，绑定revision+baselineGeneration，checking不显示clean，危险操作有界等待初值300 ms。样式不递增版本，保存更换基线后旧比较结果拒绝。
- 轻量行扫描只处理可见区±一屏及变更行，围栏状态传播到收敛即止；后台计算、主 actor 有界应用展示属性，不整体重设 attributed string。
- 高亮覆盖标题、强调/粗体、行内/围栏代码、链接/图片、列表/引用、表格分隔。初值单块 >100 KB/单行 >10 KB 降为普通文本，阈值依 G0 实测校准。
- TextPositionIndex 对同一快照维护 UTF-8/UTF-16 半开区间转换，覆盖中文、Emoji、组合字符和 Tab。

### 4.5 S1-05：安全 Markdown 与预览

流水线：不可变快照 → 约150 ms合并 → 后台解析 → AST安全序列化/raw HTML清洗 → 原生版本核验 → Web版本核验 → 替换正文 → 受控高亮/测量 → 锚点恢复。

- R-01 完整支持 CommonMark/GFM 指定子集，包括 Setext、硬换行、引用/自动链接、嵌套列表/引用、表格对齐、只读任务框、缩进/围栏代码。不启用脚注、front matter、公式或 Mermaid。
- AST 适配后不暴露第三方节点；可信结构按白名单构造 SafeDocument，raw HTML 不确定则转义；用户 data-*、事件、任意样式及执行型内容不能进入安全模型。
- 预览壳、CSS、TS 编译产物全本地打包；非持久 WKWebsiteDataStore，CSP 默认拒绝，应用脚本隔离，不使用 unsafe-eval，不把文档作为顶层 file URL。
- 桥接 envelope 校验 protocolVersion、DocumentID、BindingEpoch、revision、messageType、来源 WebView/main frame、数值及长度。不得提供通用文件读写或任意原生调用。
- 远程资源和导航默认阻止；阶段 3 资源模块接入前只安全占位。不能因功能未完成而让 img/srcset/CSS/SVG 发起直连。
- 预览代码高亮仅打包 Swift、JS、TS、Python、JSON、HTML、CSS、Bash；未知或超大代码降级为文本，不显示复制按钮和语言徽标。
- 每窗口最多一个活动预览；每文档仅最新待请求，渲染并发每窗口1/全应用2。主选/回退共用调度器，回退惰性最多2个受限清洗上下文，各自串行并重置绑定，不加全局单槽。大文档取消必须停止计算，公平性/取消按G0校准阈值验收。
- SafeDocument只含位置无关安全结构、未解析资源/链接引用及锚点；运行时BoundPreview按当前源位置/LocationEpoch/授权代次构建manifest和私有句柄，不能将这些能力地址存入可跨绑定复用的缓存。
- 解析失败只保留同一会话最后有效预览；Web 进程退出推进 BindingEpoch 重建壳，不损失文本/撤销。

### 4.6 S1-06：视图与基础同步滚动

三种模式只控制正文，与侧栏独立；切换保留选择、撤销、光标、两栏锚点和分栏比例。单栏占满正文，Preview 仍可保存。

同步默认启用，菜单开关保存在当前会话，新会话及重启默认开。按源码块/DOM blockID 与块内比例映射，程序跟随带 sequence 防反馈；重新启用以最近正文交互栏为源。无法精确映射时邻近回退，不能用全文百分比作为主算法。

几何只测视口±一屏，ResizeObserver 增量失效、批量先读后写；几何表绑定 renderedRevision，不用旧几何映射新文本。更新前后恢复顶部块，锚点消失寻找邻近块，不突然跳顶。阶段 2/3 再验证跨会话及图片高度变化组合场景。

### 4.7 S1-07：保存、另存为与关闭事务

```text
绑定活动 DocumentID
 → 确定目标（已有路径即刻；首存/另存为等待原生面板返回）
 → 捕获文本、revision、编码、源基线及独立TargetExpectation
 → 混合换行首次确认（平票默认 LF，取消不写）
 → 检测磁盘版本/冲突，申请短期目标资格
 → 记录操作恢复信息，prepare 临时产物
 → 最终身份、权限、目标版本、注册表复核
 → 安全替换或排他新建
 → CommitReceipt 更新被保存快照基线
 → 比较当前内容，保留后续编辑的 dirty
```

- 对已有路径，在命令触发主 actor 周期捕获；面板路径在返回后捕获，所有入口一致。
- TargetExpectation区分absent（父目录身份+名称）、sourceBaseline（当前源身份+字节指纹）、confirmedExisting（普通已有目标的确认版本）。源diskBaseline不能用于比较另存目标。普通目标覆盖绑定具体版本；无法证明系统面板确认版本时补应用确认；确认后变化释放资格重确认或中止。absent排他创建，竞争出现目标不中途转覆盖；另存选回源文件仍走源冲突保护。阶段3导出复用该协议。
- 同一会话保存串行、合并最新待保存请求；保存期间持续输入不阻塞，r10 保存成功不能将 r11 标为已保存。
- 无权、空间不足、身份不确定、外部变化分别反馈；不存在安全替换能力时中止，不退回 truncate-and-write。
- 提交后取消不能报告“未写入”；不确定结果保留快照与操作记录、复核磁盘，不错误清脏。操作恢复记录从阶段 1 写入，启动消费在阶段 2 完成。
- 保存前发现外部变化不得静默覆盖：提供另存为或取消；阶段 2 完成 Reload/Overwrite 完整决策。文件已删除不普通 Save 偷偷复活。
- 另存为成功保留 DocumentID/Undo，原文件不动；原子更新源位置、LocationEpoch、索引和资源基准。目标已由其他会话占用则拒绝；失败保持旧位置。
- 关闭 dirty 文档显示 Save/Don’t Save/Cancel，保存失败或取消面板不关闭；保存中又编辑则再次处理该会话。空白从未编辑文档可关闭。
- 从一开始使用CloseCoordinator。放弃确认绑定revision，安全结束IME并复核后取得closing资格；异步墓碑/操作记录清理期间禁止该会话所有字符修改入口，失败解锁并保留旧有效恢复记录，成功紧接移除。clean关闭异步清理同样处理；保存期间仍可输入，不把整个保存过程锁成只读。未启用正式草稿时不伪称清理成功，已写的操作恢复记录同样服从放弃协议。
- 关闭窗口暂停新增/移入；退出统一拦截新建、Finder/拖放/Recent打开及在途注册，暂存请求，取消后复核恢复；最终核验无未处理会话及在途提交再答复系统。阶段2扩展到全应用多会话，不另造退出路径。

### 4.8 执行顺序、交付与测试

顺序：S1-01 → S1-02/S1-03 → S1-04 → S1-05/S1-06 → S1-07 → 集成验收。安全保存可与安全预览按模块推进，但没有对应保护时不可合并成“可用”演示版本。

交付：可构建内部 App、Core 与 Web 测试、锁文件/资源清单、双语目录、文件事务夹具、G1 证据。后续证据建议存 `evidence/stage-1/`，包含提交/环境/步骤/结果，不生成空白通过报告。

测试分层：纯核心验证状态/判脏/清洗；确定性时序验证保存与迟到渲染；真实沙盒验证编码/替换/错误；WebKit 验证 CSP/桥接；真实输入法和双语菜单人工复核。性能指标持续采样，不等阶段 4 才首次测量。
